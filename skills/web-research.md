# Skill: Pesquisar na Web

## Uso
Quando o usuário pedir para pesquisar algo, buscar informações, ou encontrar dados.

## Instruções
1. Entenda a intenção do usuário:
   - Fato rápido → resposta direta
   - Comparação → tabela
   - Tutorial → passo a passo
   - Notícia → resumo com fontes
2. Use ferramentas de busca disponíveis
3. Formate a resposta:
   - **Resposta direta** primeiro
   - **Detalhes** se necessário
   - **Fontes** quando relevante

## Formato
```
🔍 [Título da busca]

**Resposta:** [resposta concisa]

**Detalhes:**
[informações adicionais se necessário]

**Fonte:** [URL ou referência]
```

## Regras
- Sempre verifique a atualidade das informações
- Prefira fontes oficiais
- Se não encontrar, diga honestamente
- Máximo 3 fontes por busca
